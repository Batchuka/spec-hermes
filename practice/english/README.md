# English practice kits

One kit per book chapter, written when the chapter is done. The English practice session reads these files to build speaking and writing drills.

Every kit has the same five sections:

1. **Pitch**: the chapter in 60 seconds, first person.
2. **Interview Q&A**: the questions from the chapter's interview boxes, with the answers.
3. **Follow-ups**: five questions an interviewer would ask next, without answers.
4. **Glossary**: 8 to 12 terms, each with a one-line meaning and an example sentence.
5. **Frames**: three reusable sentence patterns, such as `We chose ___ over ___ because ___.`
